**Мәтінді кері нормалау** (inverse text normalization, ITN) — мәтінді айтылу түрінен жазбаша түрге айналдыру. Сөйлеуді тану жүйесі айтылу түрін береді, ал оқырманға және одан кейінгі барлық жүйелерге жазбаша түрі қажет.

ITN *семиотикалық класстармен* жұмыс істейді: сандар, күндер, уақыт, ақша сомалары, аббревиатуралар, мекенжайлар және жазбаша түрі айтылуынан өзгеше болатын басқа да нәрселер:

```
двенадцать сорок пять           ->  12:45
он бес мың                      ->  15 000
айгуль собачка гмайл точка кз   ->  aigul@gmail.kz
кока кола                       ->  Coca-Cola
```

Бірдеңені түрлендірмес бұрын, **қай сөздердің семиотикалық классқа жататынын және нақты қайсысына жататынын** анықтап алу керек. Егер спанды өткізіп алсаңыз, транскрипция оқылмайтын болып қалады. Артық сөзді белгілесеңіз, дұрыс көрінетін, бірақ қате транскрипция аласыз: кәдімгі сөзді санға немесе атауға айналдырған жүйе фактіні ойдан шығарды, және кейін транскрипцияны оқыған ешкім мұны байқамайды.

Бұл тапсырмада сіз осы бірінші қадамды — және тек соны ғана жасайсыз.

Сөйлем токендер тізбегі түрінде берілген. Әр токенге **BIO** форматында белгі тағайындау керек:

- O — токен ешбір спанға кірмейді;
- B-<CLASS> — токен CLASS классының спанын бастайды;
- I-<CLASS> — токен алдыңғы токен бастаған спанды жалғастырады.

*Спан* — адам бір класстың бір жазбасы ретінде жазатын, қатар тұрған токендердің максималды тобы. Мұндай белгілеу BIO деп аталады және мәтіннен бөліктерді (есімдер, мекенжайлар, күндер) бөліп алу қажет болған барлық жерде қолданылады.

Сегіз класс бар:

| класс | бұл не | адам қалай жазар еді |
| --- | --- | --- |
| `CARDINAL` | сан | `15 000` |
| `ORDINAL` | реттік сан | `17-ші` |
| `DECIMAL` | бөлшек сан | `1,5` |
| `DATE` | айдың күні немесе жыл | `23-і` |
| `TIME` | сағаттағы уақыт | `5:30` |
| `MEASURE` | өлшем бірлігі бар шама — ақша мен пайыздар да | `3 л`, `15 000 теңге`, `40%` |
| `EMAIL` | айтылған пошта мекенжайы | `aigul@gmail.kz` |
| `WHITELIST` | атау, техникалық термин немесе аббревиатура | `Coca-Cola`, `attention`, `СМС` |

Жазбаша түрлері әр класстың *нені* білдіретінін түсіну үшін көрсетілген; оларды шығарудың қажеті жоқ.

Белгіні сөздің өзі емес, оның айналасындағы сөздер анықтайды. Төмендегі барлық мысалдарда бірдей сөз қолданылған, ал біріншісінде ол мүлдем сан емес:

```
адалдық ақыры бір көрінеді деп айтты
O       O     O   O        O   O

говорил двадцать   три        раза
O       B-CARDINAL I-CARDINAL O

встречаемся в три    тридцать
O           O B-TIME I-TIME

выйдем через три       минут
O      O     B-MEASURE I-MEASURE

мы используем ллама       три         в проде
O  O          B-WHITELIST I-WHITELIST O O

жүз       жиырма    келілік   қап
B-MEASURE I-MEASURE I-MEASURE O
```

Өлшем бірлігі немесе валюта сөзі спанға кіреді; саналатын зат — кірмейді; есімдер сыртта қалады.

## Кіріс форматы

Оқыту және тест жиынтықтарында сөйлемдердің үш түрі кездеседі:

- толығымен қазақ тілінде;
- толығымен орыс тілінде;
- аралас, яғни қазақ және орыс сөздері бір сөйлемде келеді.

Сөйлемдер токендерге бөлініп қойылған және бір-біріне тәуелсіз. Кіріс деректерде **цифрлар, тыныс белгілері және бас әріптер жоқ** — мұның бәрін адам жазу кезінде өзі қосар еді. **Тек кириллица** қолданылады: кірісте латын әріптері мен басқа әліпбилер жоқ, шет тілдік атаулар айтылуы бойынша жазылған.

Үш файл берілген:

- train.csv — sent_id , token_id , token , label бағандары; 738 843 сөйлем;
- test.csv — sent_id , token_id , token бағандары; 146 797 сөйлем;
- sample_submission.csv — шешім үлгісі, барлық белгілер O .

Бағандар:

- sent_id — сөйлем идентификаторы;
- token_id — токеннің сөйлемдегі орны, 0 -ден бастап;
- token — токеннің өзі;
- label — сегіз класстың бірімен O , B-<CLASS> немесе I-<CLASS> . Мақсатты айнымалы.

## Шығыс форматы

`solution.csv` атты бір CSV-файл жіберіңіз: тақырып жолы және `test.csv` файлының әрбір токеніне дәл бір жолдан (кез келген ретпен).

```
sent_id,token_id,label
s000000,0,O
s000000,1,B-TIME
s000000,2,I-TIME
```

Сол класстың спанын жалғастырмайтын `I-` белгісі жаңа спанның басы ретінде оқылады.

**Маңызды:** тек `solution.csv` файлын жіберіңіз, бастапқы код қажет емес. Егер `test.csv` файлының қандай да бір токені үшін жол болмаса немесе екі рет кездессе, егер `label` бағаны болмаса немесе басқаша аталса, сондай-ақ егер `label` мәні рұқсат етілген белгілер жиынына кірмесе, шешім қабылданбайды.

## Бағалау жүйесі

Шешім **дәл шекаралары бар span-level F1** метрикасымен бағаланады. Спан, егер қазылар кілтінде дәл сол бірінші токенмен, дәл сол соңғы токенмен және дәл сол класспен спан болса ғана, дұрыс деп есептеледі. Жартылай сәйкестік ештеңе бермейді.

TP — дұрыс табылған спандар саны, FP — сіздің шешіміңізде бар, бірақ кілтте жоқ спандар саны, FN — кілтте бар, бірақ сіздің шешіміңізде жоқ спандар саны болсын. Онда

```
precision = TP / (TP + FP)
recall    = TP / (TP + FN)
F1        = 2 · precision · recall / (precision + recall)
```

`TP = 0` болғанда, `F1 = 0` деп есептеледі. Әр талпыныс үшін балл — `100 · F1`, екі ондық таңбаға дейін дөңгелектелген. Тек `O` белгілерінен тұратын шешім `0.00`, ал кілтпен сәйкес келгені — `100.00` балл алады.

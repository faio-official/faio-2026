## Тапсырма

Ернияз бен Гаухар алты моторлы екі аяқты робот құрастырды. Роботты шағын нейрондық желі басқарады: кірісіне ол 18 сан (роботтың күйі мен берілген жылдамдық) алады, ал шығысына 6 сан (моторларға арналған сигналдар) береді. Сіздің міндетіңіз — робот берілген жылдамдықпен жүріп, құлап қалмайтындай осы желінің салмақтарын табу. Тек салмақтарды жіберу керек; қазылар алқасы оларды симуляторда өздері іске қосады.

## Орта

Орта — физикалық симулятордағы екі аяқты робот (Gymnasium / MuJoCo-дағы Walker2d). Ол қадамдар бойынша жұмыс істейді: әрекетті алады, робот физикасын бір қадамға (0.008 секунд) ілгерілетеді және жаңа бақылау мен сыйақыны қайтарады. Іске асырылуы — starter kit-тегі `environment.py`.

- Бақылау — 18 сан: робот бөліктерінің орны мен жылдамдықтары (17 сан) және мақсатты жылдамдық v_target.
- Әрекет — [−1, 1] аралығындағы 6 сан, әр моторға бір-бірден.
- Мақсатты жылдамдық эпизодтың басында таңдалады, v_target ∼ Uniform(0.8, 5.0) м/с, және оның соңына дейін өзгермейді.
- Эпизод робот құлағанда немесе 1250 қадамнан (10 секунд) кейін аяқталады. Эпизод қайтарымы — сыйақылардың қосындысы, ең жоғарысы 1312.5.

**Бір қадам үшін сыйақы:**

```
r = exp(−4 (v − v_target)²) + 0.05 − 0.001 (a₁² + ⋯ + a₆²)
```

- Бірінші қосылғыш — жылдамдық үшін: ағымдағы v жылдамдығы мақсатты жылдамдықпен сәйкес келгенде 1-ге тең болады және айырмашылық өскен сайын кемиді.
- 0.05 — робот құламаған әрбір қадам үшін.
- Соңғы қосылғыш — энергия үшін айыппұл: a₁, …, a₆ алты мотор сигналының квадраттарының қосындысы.
- Бір қадам үшін ең жоғары сыйақы шамамен 1.05.

## Стратегия

Әрекет бақылаудан дәл былай есептеледі (`policy.py` файлы):

```
def act(obs, w):
    x = (obs - w["obs_mean"]) / w["obs_std"]
    x = np.clip(x, -10.0, 10.0)
    x = np.tanh(x @ w["W1"] + w["b1"])   # 18 -> 64
    x = np.tanh(x @ w["W2"] + w["b2"])   # 64 -> 64
    a = x @ w["W3"] + w["b3"]            # 64 -> 6
    return np.clip(a, -1.0, 1.0)
```

`W1 … b3` — 18 → 64 → 64 → 6 желісінің салмақтары (5766 сан). `obs_mean`, `obs_std` — бақылауларды нормалау константалары. Әрекет тек ағымдағы бақылауға байланысты.

## Шешім форматы

Бір `submission.npz` файлы — дәл 8 `float32` типті массивтен тұратын NumPy-архиві:

| Массив | Өлшемі |
| --- | --- |
| `W1` | `(18, 64)` |
| `b1` | `(64,)` |
| `W2` | `(64, 64)` |
| `b2` | `(64,)` |
| `W3` | `(64, 6)` |
| `b3` | `(6,)` |
| `obs_mean` | `(18,)` |
| `obs_std` | `(18,)` |

Талаптар: барлық мәндер шекті (NaN және Inf болмауы керек), `obs_std` мәндерінің барлығы нөлден үлкен, файлда басқа массивтер жоқ, файл өлшемі 1 МБ-тан аспайды.

Бұл форматқа сәйкес келмейтін файл 0 ұпай алады.

## Бағалау

Жүйе стратегияны **50 жасырын эпизодта** (seed-тер, яғни мақсатты жылдамдықтар мен бастапқы күйлер белгісіз) іске қосады, олар барлық қатысушылар үшін бірдей. Файлды бірнеше рет жіберуге болады: **барлық жіберілген файлдар арасындағы ең жақсы ұпай есепке алынады**.

R — осы эпизодтар бойынша орташа қайтарым болсын:

```
score = 100 · min(1, R / 1312.5)
```

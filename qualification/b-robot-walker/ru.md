## Задача

Ернияз и Гаухар собрали двуногого робота с шестью моторами. Роботом управляет маленькая нейронная сеть: на вход она получает 18 чисел (состояние робота и заданная скорость), на выход даёт 6 чисел (сигналы моторам). Ваша задача — найти веса этой сети, при которых робот идёт с заданной скоростью и не падает. Отправить нужно только веса; жюри само запустит их в симуляторе.

## Среда

Среда — двуногий робот в физическом симуляторе (Walker2d из Gymnasium / MuJoCo). Она работает по шагам: получает действие, продвигает физику робота на один шаг (0.008 секунды) и возвращает новое наблюдение и награду. Реализация — `environment.py` в starter kit.

- Наблюдение — 18 чисел: положение и скорости частей робота (17 чисел) и целевая скорость v_target.
- Действие — 6 чисел в [−1, 1], по одному на мотор.
- Целевая скорость выбирается в начале эпизода, v_target ∼ Uniform(0.8, 5.0) м/с, и не меняется до его конца.
- Эпизод заканчивается, когда робот падает, или после 1250 шагов (10 секунд). Возврат эпизода — сумма наград, максимум 1312.5.

**Награда за шаг:**

```
r = exp(−4 (v − v_target)²) + 0.05 − 0.001 (a₁² + ⋯ + a₆²)
```

- Первое слагаемое — за скорость: равно 1, когда текущая скорость v совпадает с целевой, и убывает с ростом разницы.
- 0.05 — за каждый шаг, на котором робот не упал.
- Последнее слагаемое — штраф за энергию: сумма квадратов шести сигналов моторам a₁, …, a₆.
- Максимальная награда за шаг около 1.05.

## Policy

Действие вычисляется из наблюдения ровно так (файл `policy.py`):

```
def act(obs, w):
    x = (obs - w["obs_mean"]) / w["obs_std"]
    x = np.clip(x, -10.0, 10.0)
    x = np.tanh(x @ w["W1"] + w["b1"])   # 18 -> 64
    x = np.tanh(x @ w["W2"] + w["b2"])   # 64 -> 64
    a = x @ w["W3"] + w["b3"]            # 64 -> 6
    return np.clip(a, -1.0, 1.0)
```

`W1 … b3` — веса сети 18 → 64 → 64 → 6 (5766 чисел). `obs_mean`, `obs_std` — константы нормализации наблюдений. Действие зависит только от текущего наблюдения.

## Формат решения

Один файл `submission.npz` — NumPy-архив ровно с 8 массивами типа `float32`:

| Массив | Размер |
| --- | --- |
| `W1` | `(18, 64)` |
| `b1` | `(64,)` |
| `W2` | `(64, 64)` |
| `b2` | `(64,)` |
| `W3` | `(64, 6)` |
| `b3` | `(6,)` |
| `obs_mean` | `(18,)` |
| `obs_std` | `(18,)` |

Требования: все числа конечные (без NaN и Inf), все значения `obs_std` больше нуля, других массивов в файле нет, размер файла не более 1 МБ.

Файл, не соответствующий этому формату, получает 0 баллов.

## Оценка

Система запускает policy в **50 скрытых эпизодах** (seed'ы, а значит целевые скорости и начальные состояния, неизвестны), одинаковых для всех участников. Отправлять файл можно несколько раз: **в зачёт идёт лучший балл** среди всех отправленных файлов.

Пусть R — средний возврат по этим эпизодам:

```
score = 100 · min(1, R / 1312.5)
```

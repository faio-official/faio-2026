Вы оказались перед древним артефактом — Кубом Отражений.

По легенде, тот, кто заперт внутри куба, не может выйти обычным путём: пространство внутри него искривлено, раздроблено на множество зеркальных слоёв и скрытых измерений. Чтобы открыть проход наружу, необходимо понять истинную структуру этого пространства.

Мудрецы прошлого оставили лишь одно правило: если удастся **сжать пространство до его скрытой сущности**, а затем **восстановить его без существенных искажений**, куб признает, что вы раскрыли его устройство, и откроет выход.

Вам предоставлен набор данных $X \in \mathbb{R}^{N \times 128}$, описывающий наблюдения из пространства внутри куба.

Ваша задача — построить алгоритм, который находит максимально компактное представление объектов и при этом позволяет точно восстановить исходные данные.

Необходимо реализовать класс `Compressor` с тремя методами:

- `fit(X_train)` — изучает структуру пространства по обучающим данным;
- `encode(X)` — сжимает объекты в представление размерности $k$;
- `decode(Z)` — восстанавливает исходные 128 признаков по сжатому представлению.

**Ограничение на посылки.** По каждой задаче можно отправлять не более одной посылки в минуту.

Здесь $1 \le k \le 128$.

Цель — найти представление наименьшей размерности, которое всё ещё позволяет восстановить пространство достаточно точно и тем самым открыть путь наружу.

Обучающий набор данных доступен в файле `train.csv`.

Каждая строка содержит один объект с 128 признаками.

Проверяющая система автоматически создаёт экземпляр класса `Compressor` и вызывает методы `fit`, `encode` и `decode`.

Данные передаются в виде двумерных массивов NumPy.

Чтение из стандартного ввода не требуется.

Отправьте один Python-файл с реализацией класса `Compressor`.

Класс должен содержать методы:

- `fit(X_train)`
- `encode(X)`
- `decode(Z)`

Метод `encode` должен возвращать массив $Z \in \mathbb{R}^{N \times k}$ типа `float32`.

Метод `decode` должен возвращать восстановленные данные $\hat X \in \mathbb{R}^{N \times 128}$.

Количество и порядок объектов должны сохраняться.

Все возвращаемые значения должны быть конечными.

Вывод в стандартный поток не требуется.

Качество восстановления оценивается с помощью Normalized Mean Squared Error (NMSE):

$$
\operatorname{NMSE}(X,\hat X) =
\frac{\|X-\hat X\|_F^2}
{\|X-\mathbf{1}\mu_{\mathrm{train}}^{T}\|_F^2},
$$

где $\hat X$ — восстановленные данные, $\mu_{\mathrm{train}}$ — вектор средних значений признаков обучающей выборки, а $\mathbf{1}$ — вектор из единиц.

Итоговый балл вычисляется по формуле:

$$
S =
\begin{cases}
100\left(1-\dfrac{k}{128}\right), & \operatorname{NMSE}\leq 0.01,\\
0, & \operatorname{NMSE}>0.01.
\end{cases}
$$

Здесь $k$ — размерность сжатого представления.

Чем меньше $k$, тем выше балл, при условии, что ошибка восстановления не превышает 0.01.

Оценивание производится на скрытой тестовой выборке.

Максимальный возможный балл — 100.

Ограничения:

- Разрешённые библиотеки: NumPy, SciPy, scikit-learn и стандартные библиотеки Python.

Метод `decode` может использовать только сжатое представление и параметры, полученные во время обучения.

Передача исходных тестовых данных в обход сжатого представления запрещена.

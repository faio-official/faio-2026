# FAIO 2026 — День 1

<p align="center"><a href="./README.md">English</a> · <a href="./README.kz.md">Қазақша</a> · <b>Русский</b></p>

---

Добро пожаловать на первый день олимпиады. Сегодняшние четыре задачи дают вам сигналы разной природы — видео, звук, многомерные векторы и текст — и просят извлечь из них структуру. Решать можно в любом порядке; каждая задача оценивается отдельно. По каждой задаче вы можете выбрать до 2 посылок для итогового зачёта — если не выбрать, засчитываются 2 лучшие по паблик-скору. Ограничение — не более одной посылки в минуту на задачу. Удачи.

- **[A — Таинственный тир](./a-shooting-ride/ru.md).** По видео с камеры аттракциона предскажите, в какую точку целиться: выстрел должен попасть в мишень такой, какой она станет через несколько кадров — с учётом задержки выстрела.
- **[B — Печать на клавиатуре](./b-keyboard-activities/ru.md).** По короткой аудиозаписи набора на клавиатуре определите, чем занят человек — пишет код или обычный текст — только по звуку нажатий клавиш.
- **[C — Уменьшение размерности](./c-dimensionality-reduction/ru.md).** Сожмите 128-мерные данные до наименьшей возможной размерности, а затем восстановите их с минимальными искажениями.
- **[D — Умный роутер](./d-smart-router/ru.md).** Оцените каждый документ по вероятности того, что в нём остались незамаскированные персональные данные, чтобы ограниченный бюджет дополнительной проверки ушёл на самые рискованные документы.

---

## 📝 Дорешивание

Все восемь задач остаются открытыми для дорешивания на **[contest.faio.kz](https://contest.faio.kz)** — войдите, откройте контест FAIO 2026 и отправляйте решения в своём темпе. Данные по ссылкам в условиях скачиваются без аккаунта.

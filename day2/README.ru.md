# FAIO 2026 — День 2

<p align="center"><a href="./README.md">English</a> · <a href="./README.kz.md">Қазақша</a> · <b>Русский</b></p>

---

Добро пожаловать на второй день. Сегодняшние четыре задачи — это лекции, языковые модели, голоса в комнате и веб-поиск. Как и вчера, решайте в любом порядке; каждая задача оценивается отдельно. По каждой задаче вы можете выбрать до 2 посылок для итогового зачёта — если не выбрать, засчитываются 2 лучшие по паблик-скору. Ограничение — не более одной посылки в минуту на задачу. Удачи.

- **[E — Лекция вперемешку](./e-lecture-shuffle/ru.md).** Лекцию нарезали на 30-секундные фрагменты и потеряли их порядок — восстановите исходную последовательность клипов внутри каждой лекции.
- **F — Кто это написал?** По вопросу и ответу, сгенерированному ИИ, определите, какая из десяти анонимных моделей его написала — задача многоклассовой классификации.
- **[G — Направление прибытия](./g-direction-of-arrival/ru.md).** По 30 секундам четырёхканальной аудиозаписи определите и направление, откуда звучал голос говорящего, и расшифровку сказанного.
- **[H — Поисковый движок](./h-search-engine/ru.md).** Постройте спортивный поисковик: для каждого запроса упорядочьте страницы большого корпуса так, чтобы самые релевантные результаты были выше.

---

## 📝 Дорешивание

Все восемь задач остаются открытыми для дорешивания на **[contest.faio.kz](https://contest.faio.kz)** — войдите, откройте контест FAIO 2026 и отправляйте решения в своём темпе. Данные по ссылкам в условиях скачиваются без аккаунта.
